# Справки, финансови отчети, SAF-T, одит

## Справки

`GET /v1/reports?kind=…` — справки от дневника и началните салда.

| `kind` | Справка |
|-------|---------|
| `trial_balance` | шестколонна оборотна ведомост |
| `counterpart_trial` | оборотна ведомост по контрагент |
| `general_ledger` | главна книга с текущо салдо |
| `chronological` | хронологичен журнал (FIFO двойки) |
| `counterpart_chrono` | хронологичен журнал по контрагент |
| `correspondence_ledger` | главна книга по кореспонденции (водещ дебит/кредит) |
| `stock` | складова справка (приход, разход, наличности) |
| `balance_sheet` | баланс |
| `income_statement` | отчет за приходи и разходи |
| `cash_flow` | паричен поток |
| `equity` | отчет за собствения капитал |

Крайното салдо е **начално + оборот**, без нетиране; контрагентът се филтрира
по записа. `GET /v1/reports/export` дава XLSX/ODS на текущата справка.

## Финансови отчети по формули

Каталогът на бланките по СС 1 / СС 7 и стандартните формули са в кода
(`Reports.Nom`). Ред на бланка: `code|parent|kind|side|name`. Формулата е
сбор от сметки (`304Д`, `50*ОД`), кореспонденции (`702Д/304К`) и препратки
(`@pl.e.5a`); празен низ е нула, освен сборът на група.

| Метод | Път | Описание |
|-------|-----|----------|
| GET | `/v1/fs/lines` | редове на отчетите |
| GET / PUT | `/v1/fs/formulas` | формули по ред |
| POST | `/v1/fs/formulas/defaults` | шаблони |
| POST | `/v1/fs/formulas/validate` | проверка |
| POST | `/v1/fs/formulas/clear` | изчистване |

## SAF-T

`GET /v1/saft/export` по **BG_SAFT_Schema V1.0.1**. Параметри:

| Параметър | Стойност |
|-----------|----------|
| `period` | `YYYY-MM-01` (задължителен) |
| `mode` | `monthly` (по подразбиране), `annual`, `ondemand` |
| `date_from`, `date_to` | само за `ondemand` |

| Режим | Съдържание |
|-------|------------|
| `monthly` | сметкоплан, дневник с FIFO кореспонденции, клиенти/доставчици, фактури продажби/покупки, плащания, данъчна таблица, продукти |
| `annual` | ДМА със счетоводна и данъчна оценка, придобивания за годината |
| `ondemand` | наличност и стокови движения за периода с начална и крайна наличност |

Заглавката носи Ownership (действителни собственици и крайни майки), контакт,
IBAN и област `BG-01…BG-28`. Месец без банково плащане пак пише секция
Payments с нула записа. Пространство от имена:
`mf:nra:dgti:dxxxx:declaration:v1`.

`Saft.Mappings` свързва Дт/Кт кореспонденции с тип движение
(`stock`/`asset`/`cash`) по активната фирма:

| Метод | Път |
|-------|-----|
| GET / POST | `/v1/saft/movement-mappings` |
| POST | `/v1/saft/movement-mappings/defaults` |
| PATCH / DELETE | `/v1/saft/movement-mappings/:id` |

## Одит

`audit_logs` пази потребител, време, обект, действие и снимки (old/new) за
документите и настройките.

| Метод | Път | Описание |
|-------|-----|----------|
| GET | `/v1/audit-logs` | списък с филтри: `entity_type`, `entity_id`, `action`, `user`, `from`, `to`, `changed_only`, `q` |
| GET | `/v1/audit-logs/:entity_type/:entity_id` | история на обект |

Правата за одита зависят от типа обекта: например `invoice` → `invoices`,
`journal` → `journal`, `bank_tx` → `banking`, `stock`-типове → `stock`.
