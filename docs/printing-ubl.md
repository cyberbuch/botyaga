# Печат, UBL, външни услуги

## Печат

Един HTML5 документ се превръща в това, което търси клиентът.

| Формат | Как се прави |
|--------|--------------|
| PDF | HTML → Chromium sidecar (Gotenberg + DejaVu) по адрес `BOTYAGA_PRINT_URL`. Без него PDF връща 503 |
| DOCX / ODT | нативно от block-ове (`:zip` + XML), без външни библиотеки и без sidecar |
| XLSX / ODS | от таблица (grid) с числови клетки и `bg` формат; ZIP е без компресия, за да мине кирилицата като UTF-8 |

Печат се ползва за фактура (`GET /v1/invoices/:id/print`) и за вътрешен протокол
(`GET /v1/internal-docs/:id/print`). Сумата словом е на български
(`Printing.Words`).

Съдържание по образеца на фактурата: получател/доставчик (ЕИК, ДДС, МОЛ, лице за
контакт), редове с колона **ДДС%**, данъчна основа/ДДС/общо, словом. При плащане
с банка се изписват **Начин: По банкова сметка**, срок, **Банка / IBAN / BIC** от
избраната банкова сметка на фактурата (`bank_account_id`). На края има подписи: **Получил** = лице за контакт на контрагента,
**Съставил** = МОЛ на фирмата издател.

## UBL

експорт — UBL 2.1 / Peppol BIS Billing 3.0, фирмата е доставчик:

| Вид документ | Код |
|--------------|-----|
| фактура | `380` |
| кредитно известие | `381` (CreditNote) |
| дебитно известие | `383` |
| проформа | `325` |

При валута, различна от EUR, се добавя `TaxCurrencyCode`. `PayeeFinancialAccount`
носи IBAN/BIC на избраната банкова сметка на фактурата.
`GET /v1/invoices/:id/ubl`.

**Вход** — `POST /v1/scans/ubl` и `Ubl.Parser` (streaming, без база) създават
преглед за чернова; `Ubl.Import` записва черновата с абсорбиране на ДДС.

## Сканиране и разпознаване

`POST /v1/scans/extract` — сканирана фактура през Mistral OCR, после JSON за
чернова. Ключът се взема от настройките на фирмата.

`Pnmap` — име от сканиран документ → локален артикул
(`product_name_mappings`). При нерегистрирана по ДДС фирма и входяща фактура
центовото абсорбиране е без rounding drift.

## Курсове

`Rates` — курсове на ЕЦБ за 1 EUR: дневен фид и история за 90 дни, as-of
търсене (най-близкият по-ранен при липса) и кръстосан курс.

| Метод | Път |
|-------|-----|
| GET | `/v1/exchange-rates` |
| GET | `/v1/exchange-rates/rate`, `/cross` |
| POST | `/v1/exchange-rates/import` |

## VIES и адреси

`GET /v1/counterparts/vies-lookup` — справка по VIES; `POST /v1/counterparts/vies`
— нов контрагент от резултата.

`POST /v1/addresses/parse` — адрес → полета (улица, номер, сграда, допълнително,
вид, регион) за SAF-T. При нужда от невярно разбиване може да се ползва
Mistral с ключ в настройките на фирмата.
