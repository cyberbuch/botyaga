# botyaga — документация

**botyaga** е самостоятелна счетоводна програма. Тя е уеб приложение с JSON
API (Elixir + Phoenix) и интерфейс (Next.js), което покрива целия счетоводен
цикъл: фирми и обекти, сметкоплан, фактури, дневник, счетоводни периоди,
ДДС, банки, дълготрайни активи, склад, производство, дивиденти, справки,
финансови отчети, SAF-T, печат и архив.

Продуктът е завършен: **245 теста зелени** (проверено на 2026-11-16),
собствен интерфейс и контейнерен стек за локална и продукционна употреба.

## Бърз старт

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

Това вдига четири контейнера: PostgreSQL, Chromium sidecar за PDF печат,
API (:8093) и интерфейс (:3021). Отвори <http://127.0.0.1:3021>.

За разработка без Docker:

```bash
docker compose -f deploy/docker-compose.yml up -d postgres   # само базата на :5433
mix setup                                                     # deps, база, миграции
mix phx.server                                                # API на :8093
cd frontend && npm install && npm run dev                     # интерфейс на :3021
```

При първи старт с празна база се създава потребител `superadmin`. Паролата се
генерира еднократно и се отпечатва в лога; за парола по избор задай
`BOTYAGA_SUPERADMIN_PASSWORD` преди старта.

Проверка на готовността: `GET /ready` → `{"status":"ok","database":"up"}`.

## Принципи

- **Базова валута EUR.** Черно сторно е отрицателен знак върху същите
  Дт/Кт сметки, без обръщане на страните.
- **Сумите в JSON са низове** — 2 знака за пари, 4 за количество. Вътрешно
  аритметиката е цяло число с мащаб 1 000 000 (`Dec`).
- **`company_id` изолира данните** по фирма; чужд ред дава 404.
- **Всяка заявка минава през gate.** Извън шестте публични входни пътя няма
  достъп без валиден токен; непознат път се отказва (deny by default).
- **Модулите се делят с header-и.** Размер: мек gate 400 реда, твърд 600
  (`scripts/filesize.sh`).
